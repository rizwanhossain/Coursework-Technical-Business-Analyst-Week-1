# JTBDs from Legacy Trust Bank Stakeholder Quotes

## Quote-to-JTBD Transformations

### 1. Workload Prioritization- Operations
**Original Quote:** "Straightforward cases get delayed because they are queued behind complex ones with no priority logic."

**JTBD:** When I manage my workload, I want straightforward cases to be prioritized appropriately so they're resolved quickly.

---

### 2. Contact History Visibility
**Original Quote:** "I cannot tell which customers have already been contacted this month without manually checking three different sheets."

**JTBD:** When I prepare to contact a customer, I want to see how many times they've been contacted this month so I don't duplicate outreach.

---

### 3. Case Status Context
**Original Quote:** "Status updates do not capture why a case changed state, only that it did."

**JTBD:** When I review a case's history, I want to understand why it changed status so I can make informed decisions.

---

### 4. Payment Communication Clarity
**Original Quote:** "The current system treats payment promises the same as payment confirmations, which creates confusion."

**JTBD:** When I record customer communication about payment, I want to distinguish between payment promises and confirmed payments so there's no confusion about what's actually owed.

---

### 5. Callback Accountability
**Original Quote:** "Cases get stuck in 'pending callback' status indefinitely because the callback date is never enforced."

**JTBD:** When I schedule a customer callback, I want the system to track and enforce the deadline so callbacks happen on time.

---

### 6. Consistent Status Definitions
**Original Quote:** "Different representatives use different status codes, which makes reporting meaningless."

**JTBD:** When I report on case activity, I want consistent status definitions across the team so reporting is accurate and actionable.
